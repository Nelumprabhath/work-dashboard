☁ Cloud Sync — private GitHub Gist

Tasks sync through a secret Gist in your own GitHub account. The token is stored only in this browser — never in the repo.
Setup: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → tick only gist → paste here. Leave Gist ID blank on the first device — Sync creates one and shows the ID. Paste that ID on your other devices.
